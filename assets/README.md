# Recursos de presentación

Capturas reales de W4lterSec en Kali Linux 2026.3 dentro de VirtualBox:

- `capturas/escritorio.png`: escritorio y barra Polybar.
- `capturas/terminales.png`: ventanas en mosaico e información del sistema.
- `capturas/transparencia.png`: acabado Glass y bordes de Kitty.

Las tres capturas aparecen abiertas en la portada. Se conservan los originales.
El vídeo para web está alojado como adjunto multimedia de GitHub y se reproduce
en el README y la guía. El original se conserva en la entrega `tutorial-2026-11-22`.
Los vídeos no forman parte de la descarga con `git clone`.

Los fondos de `wallpapers/` y las fuentes de `fonts/` siguen siendo recursos
funcionales del escritorio instalado.
